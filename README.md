# 클럽 테니스 랭킹

테니스 멤버들이 경기 결과(단식/복식, 게임 스코어)를 입력하고 함께 순위를 보는 웹 페이지입니다.
카카오톡 단톡방에 링크만 올리면 가입·로그인 없이 누구나 볼 수 있고, **클럽 PIN**을 아는 멤버는 결과를 입력·삭제할 수 있습니다.

## 구성
- `index.html` – 화면 (순위 / 선수 기록 / 결과 입력 / 경기 기록 / 게시판 / 멤버·설정). 경기와 게시글마다 댓글을 달 수 있습니다.
- `ranking.js` – 스코어 파싱, 승자 판정, 순위 계산 (브라우저·Node 공용)
- `config.js` – Supabase 주소와 공개(anon) 키
- `supabase/` – 데이터베이스 테이블·함수 (Supabase 프로젝트 `tennis-club`, 서울 리전)
- `tests/` – `node --test tests/*.test.js`

## 순위 규칙
1. 승점 (현재: 승리 2점, 무승부 1점, 패배 0점 — "멤버 · 설정"에서 변경 가능)
2. 승률
3. 게임 득실차
4. 게임 득점 (많이 딴 순)

복식은 두 선수 모두에게 같은 결과가 반영됩니다. 세트 수와 게임 수가 모두 같으면(예: `5-5`, `6-4, 4-6`) 무승부입니다. 스코어는 팀 A 기준 게임 스코어로 `6-4`처럼 입력합니다(여러 세트면 `6-4, 3-6, 7-5`).

## 보안
- 테이블은 누구나 읽기만 가능하고, 쓰기는 PIN을 확인하는 `club_*` 함수로만 됩니다.
- **클럽 PIN**: 결과 입력, 멤버 추가. **마스터 PIN**: 경기·멤버 수정과 삭제, 승점 규칙, PIN 변경 (서버에서 검사).
- PIN은 해시로만 저장되며, 10분 동안 10번 틀리면 잠시 입력이 막힙니다.
- PIN은 "멤버 · 설정" 탭에서 바꿀 수 있습니다.

## 휴대폰 앱으로 설치 (PWA)
- 안드로이드: Chrome으로 열고 오른쪽 위 **앱 설치** 버튼(또는 ⋮ 메뉴 → 앱 설치)
- 아이폰: Safari로 열고 공유 버튼 → **홈 화면에 추가**
- 카카오톡 안에서는 설치가 안 되므로 **앱 설치** 버튼 → Chrome/Safari로 열기
- `manifest.webmanifest`, `sw.js`, `icons/` 가 설치용 파일입니다.

## 새 버전 배포 시
`index.html`의 버전 문자열(`APP_VERSION`, 스크립트 `?v=`, 화면 아래 표시)과 `version.json`을 같은 값으로 올리면,
사용자 화면에 "새 버전이 있습니다 [지금 업데이트]" 안내가 뜹니다.
