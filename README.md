# 클럽 테니스 랭킹

테니스 멤버들이 경기 결과(단식/복식, 세트 스코어)를 입력하고 함께 순위를 보는 웹 페이지입니다.

- 공유 페이지: https://claude.ai/artifact/P5sAqDbZFJwCPzZMBwvGwS (claude.ai Artifact, 공유 저장소 사용)
- `index.html` – 화면 (순위 / 결과 입력 / 경기 기록 / 멤버·설정)
- `ranking.js` – 스코어 파싱, 승자 판정, 순위 계산 (브라우저·Node 공용)
- `tests/` – `node --test tests/*.test.js`

## 순위 규칙
1. 승점 (기본: 승리 3점, 패배 1점 — 페이지에서 변경 가능)
2. 승률
3. 게임 득실차
4. 세트 득실차

복식은 두 선수 모두에게 같은 결과가 반영됩니다. 스코어는 팀 A 기준으로 `6-4, 3-6, 7-6(5)` 형식으로 입력합니다.
